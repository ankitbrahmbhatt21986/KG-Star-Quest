# KG Star Quest

A fun learning game for Jr KG and Sr KG children (English, Maths, EVS, Hindi, Rhymes) with activities and a teacher exam builder. Questions follow NCERT / CBSE foundational-stage themes.

## Run it
Open `index.html` in any browser, or use GitHub Pages:
https://tinyurl.com/KG-Star-Quest

## Features
- Randomised, non-repeating questions per subject and class
- Activities: Memory Match, Number Order, Sort It, Spell It, Trace It, Pattern
- Teacher area (default PIN 1234, change `pin` in `index.html`): create exams, view results
- Works on phones, tablets and computers. Add to Home Screen to use like an app.

## Notes
- Exams and scores are stored in the browser (localStorage) on each device. Sharing exams across devices needs a backend such as Firebase or Supabase.
- Teachers should review Hindi and rhyme content against the school syllabus.
